# 网页翻译助手

这是从当前扩展中独立出来的 Chrome / Edge Manifest V3 插件，包含划词翻译、整页自动翻译、视频字幕翻译和模型、语言、术语表、站点设置。不包含 Codex 侧边栏或书签功能。

GitHub 私有仓库：[EDwinpzy/web-translation-helper](https://github.com/EDwinpzy/web-translation-helper)。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页并启用“开发者模式”。
2. 选择“加载已解压的扩展程序”。
3. 选择本项目目录（包含 `manifest.json` 的目录）。
4. 点击工具栏上的插件图标打开设置，配置可用的翻译模型。

也可以在网页中右键使用“翻译选中文字”“翻译整页”或“还原本页原文”。新标签页、浏览器内置页面和 `chatgpt.com` 不注入翻译脚本。

## 开发与验证

项目没有构建步骤。修改源码后，在扩展管理页点击“重新加载”即可加载当前目录。

发布前至少完成一次手动冒烟验证：

1. 打开扩展设置页，确认模型、语言、术语表、视频字幕和站点规则页面可切换。
2. 在普通网页验证划词翻译与整页翻译，并确认“还原本页原文”可用。
3. 在视频页面启用字幕后，确认字幕翻译能显示并随播放器字幕更新。
4. 确认 `manifest.json` 中的版本号已按本次发布更新。

当前项目未提供自动化测试脚本，因此上述检查不能替代发布前的人工验证。
